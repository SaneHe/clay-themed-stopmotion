# 通用主题视频工作流

## 1. Brief

把用户需求压缩成一句可执行的故事：谁在什么主题世界里，为了什么目标，在什么时间内完成什么动作。把日期、地点、角色、地标、道具、平台、时长、画幅和声音要求列成变量；不要把某个示例项目的城市、职业或线路带入新任务。

## 2. 素材清单

在实现前建立素材清单，并给每个可见物体指定唯一归属：

| 组别 | 常见文件 | 需要记录的内容 |
| --- | --- | --- |
| title | 主题主体/地标 PNG、黏土纹理 | 透明度、主题色、是否包含文字 |
| environment | 室内/街道/舞台/厨房/车厢背景 | 机位、光线、可循环局部效果 |
| character | 角色透明 PNG 或多姿态图 | 服装、比例、已经内嵌的道具 |
| props | 独立道具 PNG 或 CSS 几何层 | 只放没有被角色 PNG 包含的物体 |
| motion | 雨、蒸汽、火、灯光、速度线 | 环境层，不要伪装成人物身上的物体 |
| audio | BGM、提示音、动作声、转场声 | cue 起止时间、响度和淡入淡出 |

记录尺寸、透明度、生成来源和内嵌物体。角色 PNG 若已经带杯子、包、卡片、工具、帽子或阴影，HTML/CSS 不得再画一份同义物体。

## 3. 镜头结构

短主题视频可以从以下结构开始，再按故事调整：

| 段落 | 作用 | 画面问题 |
| --- | --- | --- |
| opening | 建立主题、时间和空间 | 第一帧是否能看懂世界观 |
| setup | 角色出现并拿到目标物 | 角色和道具是否只出现一次 |
| transition | 进入新的地点或状态 | 场景变换是否有声音和动作连接 |
| action | 主要动作或冲突 | 定格节奏是否有停顿和重量 |
| result | 目标完成或产生变化 | 关键结果是否看得清 |
| end card | 简短收束 | 是否只留下正式文案 |

15–30 秒视频通常使用 5–8 段；更长的视频可以把 action 拆成多个镜头，不要用一个无限循环掩盖没有设计的时长。

## 4. 动效

每个镜头先做静态构图，再加入淡入、背景推拉、角色有限位移、道具动作、字幕进入和停顿。建议输出 30fps。角色动作按约 10–15fps 的定格感觉更新；持续数秒的背景推拉改用连续缓动，避免低频 `steps(8)` 或 `steps(10)` 让镜头跳动。位移保持有界，旋转通常控制在 1–6 度，短动作使用与动作时长匹配的 `steps(n)`，并保留短暂停顿。

如果主题有明确地点，opening 镜头的前 1–3 秒必须先展示真实地标或可识别的环境栅格素材。标题、路线图和地点文字可以叠加，但不能让抽象渐变或地图线条独占片头。

## 5. 验收清单

- 第一帧能表达主题、主体和空间，不依赖声音才能理解；地点型视频还要能看出具体地点。
- 每个角色 PNG 都已经做过全尺寸检查，并记录了内嵌物体。
- 每个可见物体都有唯一归属；没有重复的杯子、包、卡片、阴影、地标或标识。
- 每个镜头都有明确动作和字幕安全区。
- 运动开始后抽查每个镜头，确认没有白色、棕色、蓝色或灰色的无来源方块、漂移道具或错位阴影。
- 片尾只有用户要求的正式文案，没有 `preview`、`draft`、`test`、`Codex`、提示词或内部备注。
- 单独试听 BGM、环境声和事件音效，再试听成片开头 0–5 秒、主要转场和结尾；没有合适环境声素材时不使用未经处理的白噪声凑音效。
- 占位音频仅留在草稿或临时目录，明确标记，不能进入最终时间线；ffprobe 和电平读数不能代替实际试听。
- MP4 尺寸、时长、帧率和 H.264/AAC 音轨符合 brief。
- Contact sheet 包含片头、主体动作、转场、结果和片尾，并且是最终导出后重新生成的。
- 工程可以用文档中的命令重新运行，不需要手动操作浏览器。
