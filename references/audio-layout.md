# 通用声音布局

声音应服务于主题和动作，而不是固定绑定某个城市或故事。先放一条克制的音乐底，再根据镜头事件加入短促 cue；如果用户没有指定具体声音，使用描述性名称，不要把示例项目的文件名复制到新视频。

| 音轨 | 作用 | 需要记录 |
| --- | --- | --- |
| theme-bgm.wav | 主题音乐底 | 全片时长、节奏、淡入淡出、目标音量 |
| sfx-start.wav | 开始/唤醒/启动事件 | 出现的镜头和持续时间 |
| sfx-action.wav | 角色动作或物体动作 | 与动作帧的对齐点 |
| sfx-transition.wav | 场景或状态转换 | 转场起止和衰减 |
| sfx-result.wav | 结果、确认或片尾强调 | 是否需要留白 |

每个 `<audio>` 都要写清 `data-start`、`data-duration`、`data-track-index`、`data-volume` 和淡入淡出。嵌套竖屏 composition 的非零起始 cue 增加 `data-hf-media-start-basis="local"`。音乐和事件音效使用独立轨道，重要提示音出现时可以短暂压低音乐。

没有合适的环境音素材时，宁可不加，也不要把未经滤波的白噪声直接当成海浪、风、雨或火焰声。合成音效只有在经过试听、处理并确认符合画面后才能进入成片。占位音频只能留在草稿或临时目录，明确标记为占位，并且不能挂到最终 composition 时间线上。生成音频的文件名、来源和 cue 时间必须写入项目自己的音频清单。

遇到嘈杂、沙沙声或突兀声，先分别试听 BGM、环境声、事件音效，再试听混音，确认问题来自哪一层后再调整；不要仅凭总电平猜来源。

交付前至少试听：

- 各条独立音轨，确认音色适合画面、没有持续噪声或突兀切口；
- 成片开头 0–5 秒，检查淡入、叠音和首个环境 cue；
- 主要转场和结尾，检查 cue 对齐、重叠、淡出与残响。

同时用 `ffprobe` 检查编码，用 `volumedetect` 或等效工具检查平均电平和峰值。技术读数只能证明音轨存在及电平状况，不能代替听感验收。没有实际试听时，明确说明尚未试听，不要声称音质已通过检查。
